# Cody: Modular Biped Robot Project (Preview Release)

![Cody](/assets/project_thumb_cody.jpg)

Cody is the next-generation of the modular biped project from Makerforge.tech. This build is a preview release, representing the cutting edge of our robotics development efforts.

Cody is designed to be more robust, capable, and flexible than previous versions, with a focus on modularity, advanced features, and ease of customization for makers and robotics enthusiasts.

---

## Project Overview

The Modular Biped Robot Project aims to provide a flexible framework for robotics development using Python on the Raspberry Pi and Arduino platforms. 

Cody builds on this foundation, introducing a new carrier board for the Raspberry Pi Compute Module 5 (CM5) and a host of new features and improvements.

---

## Key Features

- **Audio**: I2S dual microphones and amplifier.
- **Display**: SPI-based TFT eye and OLED body displays.
- **Power**: 5V DC-DC to head, 8V DC-DC to body. USB-C or battery input.
- **Computing**: Raspberry Pi Compute Module 5 with custom carrier board.
- **Connectivity**: GPIO, I2C, UART breakouts for sensors and modules.
- **Input**: Raspberry PI AI Camera, motion sensor, dual IMUs, magnetic GPIO
